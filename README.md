# Chess Tutor

This is the starting point for a chess opening tutor. The frontend currently shows an interactive chessboard. The `backend/` directory is intentionally empty; Lichess opening data and computer move suggestions have not been implemented yet.

## Run the frontend

```sh
cd frontend
npm install
npm run dev
```

Open the local URL printed by Vite. Drag pieces or click a piece and its destination to make moves. Use the previous/next controls, click a move in the list, or press the left/right arrow keys to revisit positions. The flip control changes board orientation.
